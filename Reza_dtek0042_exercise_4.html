def _slicing(sig, file_label, segment_length = 1000):
    """
    inputs:
    sig : input array to be segmented
    file_label : label to be applied to segmented signal
    segment_length : Length in samples of the segments produced from the input signal

    outputs:
    sig_sliced : a list of segments
    label : a list of corresponding labels for the segmented signal
    """
    sig_sliced = []
    label = []

    # slicing
    for i in np.arange(int(len(sig)/segment_length)):
        sig_sliced.append( sig[i*segment_length:(i+1)*segment_length] )
        label.append(file_label)
    return (sig_sliced , label)

#code
def feature_extraction(sig, fs = 200):
    """
    inputs:
    sig : input array to extract features from
    fs : sampling frequency of input array

    outputs:
    feature_array: an array containing all the features extracted from the signal
    """
    ########################################## statistical features - time domain
    f_mean = np.mean(sig)
    f_std = np.std(sig)
    f_iqr = stats.iqr(sig)
    f_median = np.median(sig)
    f_ptp = np.ptp(sig)
    f_skew = stats.skew(sig)
    f_kurtosis = stats.kurtosis(sig)
    f_rms = np.sqrt(np.mean(sig**2))
    time_features = [f_mean, f_std, f_iqr, f_median, f_ptp, f_skew, f_kurtosis, f_rms]
    ########################################## PSD
    # transforming to zero mean and unit variance -- only do this when extracting PSD
    # Hint: transfromed_sig = function_for_scale(sig)
    transformed_sig = prep.scale(sig)
    frequencies, PSD = signal.welch(transformed_sig, fs=fs)
    freqs_arr = np.arange(0,41,4)
    PSD_binned_sum = []
    for i in range(freqs_arr.shape[0]-1):
        PSD_binned_sum.append (np.sum(PSD[np.where((frequencies >= freqs_arr[i])&(frequencies < freqs_arr[i+1]))]))

    # return the feature array
    feature_array = time_features + PSD_binned_sum
    return feature_array

features_list = []
labels_list = []

# Segment length for 5 seconds at 200 Hz
seg_length = 5 * 200
for file_path in dataFiles:
    filename = os.path.basename(file_path)
    label_str = filename.split('_')[0].lower()
    sig = np.loadtxt(file_path, usecols=2)
    segments, segment_labels = _slicing(sig, file_label=label_str, segment_length=seg_length)
    for i in range(len(segments)):
        current_segment = segments[i]
        current_label = segment_labels[i]
        extracted_features = feature_extraction(current_segment, fs=200)
        features_list.append(extracted_features)
        labels_list.append(current_label)
X_features = np.array(features_list)
y_labels = np.array(labels_list)
print(f"X Shape: {X_features.shape}")
print(f"Y Shape: {y_labels.shape}")

The signals were divided into non-overlapping segments of five seconds. With a sampling frequency of 200 Hz, each segment contains 1,000 samples.

For every segment, 18 features were extracted: eight time-domain statistical features and ten frequency-domain features representing power spectral density (PSD) across frequency bands from 0 to 40 Hz, in 4 Hz steps.

The resulting feature array has a shape of (75, 18), representing 75 segments and 18 features per segment. A corresponding label was assigned to each segment to indicate whether it originated from a normal or noisy recording.

The features were standardized before principal component analysis (PCA), ensuring that features with different scales would not dominate the analysis solely because of their numerical magnitudes.

Observations¶

Observations: PCA of SCG Signals¶

The PCA plot shows that the normal and noisy signal segments have different distributions in the reduced feature space. The normal segments form two noticeable groupings: one in the upper-left region and another extending toward the right side of the plot. The noisy segments are more widely dispersed, particularly across the lower-left and central regions.

This distribution indicates that the extracted features capture differences between the two types of recordings. In some regions, normal and noisy segments occupy distinctly different areas, suggesting that the features could help distinguish between the classes.

However, the separation is not complete. Some points from the two classes appear close together or overlap, particularly in the central part of the plot and in parts of the upper-left region. Consequently, the first two principal components do not provide a perfect visual separation of normal and noisy segments.

The PCA results therefore suggest that the extracted features have useful but limited discriminatory ability when represented by only two principal components. Additional classification analysis would be required to determine how accurately these features could distinguish between the two classes.
